HQ10W CLEAN FULL 1
Основа: V1.0.3.6, Android 12 ARM32
Плата: YG_5H080_693_RX_ZX

Установка, переустановка и откат выполняются на свой страх и риск.
Сбой питания во время записи загрузочных разделов может нарушить загрузку.

README.md — возможности, совместимость и статус проверок.
CHANGES-RU.txt — описание звука DAP, интерфейса и оптимизаций.
INSTALL-RU.txt — полная инструкция, примеры, переустановка и возврат.

MODE.txt поддерживает CHECK, INSTALL и ROLLBACK.
Начинайте с CHECK и свежего HQ10W-RESULT.txt. Продолжение — только после CHECK_OK.
Не отключайте питание и USB во время записи. Кнопку питания долго не удерживайте.

Скачать полный установочный USB-комплект:
https://github.com/vgtstptlk/hq10w-clean/releases/tag/full-1

Нужен файл HQ10W-Clean-Full-1-USB.zip из Assets. Внутри полный OTA,
заводской OTA для возврата и инструкции. Архивы Source code содержат исходники.

Ветка репозитория содержит документацию, скриншоты, текстовые отчёты
и исходники скриптов; установочный архив размещён отдельно в Releases.
